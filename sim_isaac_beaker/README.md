# 비커 붓기 — Sim-to-Real Post-Training (Isaac Sim · Isaac Lab)

**바이오 실험 비커 붓기 과제 · 시뮬레이션 파트** · Franka FR3 · FAIRINO FR5 · 멈춤, 차후 예정 (2026-11-20)

[English](README_EN.md) · [← 시뮬 실험 목록 (튜브 · 스포이드 · 비커)](../README.md)

## 1. 개요

- 실물 FR3 · FR5 에서 하는 비커 붓기 실험을 Isaac Sim 으로 옮기는 작업입니다 (11-16 시작, 11-18 멈춤). [스포이드](../sim_isaac_dropper/README.md) 실험을 먼저 하고, 붓기는 차후에 이어 갑니다.
- 장면 (책상 · 받침대 · 벽 · 조명) 은 [튜브 꽂기](../sim_isaac_tube/README.md) 의 실물 재현 실험대 규격을 그대로 씁니다 — 따로 어림한 높이를 쓰지 않습니다.

## 2. 과제

| 항목 | 내용 |
|---|---|
| 동작 | 작은 비커를 쥐어 들고, 기울여 안의 공을 큰 비커로 부음 |
| 로봇 | FR3 · FR5 — 실물 팀의 붓기 계획이 로봇마다 다름 (아래) |

## 3. 지금까지 정한 것

- **물체 모델:** 비커 (작은 · 큰) · 공 · 스포이드 · 24 칸 판 · 뚜껑 · 스포이드 거치대 · 구멍 표시 코인을 만들었습니다. 스포이드 실험이 같은 모델을 씁니다.
- **붓기 궤적:** 시뮬에서 궤적을 새로 찾지 않고 **실물 팀의 붓기 계획을 로봇마다 그대로 옮깁니다.**
  - FR3 — 비커를 45° 기울여 쥐고, 2 · 4 · 6 번 관절로 바깥쪽으로 숙여 부음 (7 번 관절 고정)
  - FR5 — 위에서 쥐고, 주로 5 번 관절로 기울임
- **제약:** 손목을 크게 돌리면 손목 카메라 선 (컴퓨터에 연결됨) 이 걸립니다. 그래서 공이 다 나오는 **가장 작은 기울기**부터 찾습니다.
