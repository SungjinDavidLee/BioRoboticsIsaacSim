# 스포이드 — Sim-to-Real Post-Training (Isaac Sim · Isaac Lab)

**바이오 실험 스포이드 과제 · 시뮬레이션 파트** · Franka FR3 · FAIRINO FR5 · 진행 중 (2026-11-20)

[English](README_EN.md) · [← 시뮬 실험 목록 (튜브 · 스포이드 · 비커)](../README.md)

그림 · 영상은 자동 시연 수집을 시작하면 더합니다.

## 1. 개요

- 실물 FR3 · FR5 실험대에서 하는 스포이드 과제를 Isaac Sim 에서 따라갑니다 (11-18 시작).
- [튜브 꽂기](../sim_isaac_tube/README.md) 실험의 실물 재현 실험대 (책상 · 받침대 · 벽 · 조명 · 카메라) 와 흐름 (자동 시연 → 실물 형식 변환 → GR00T N1.7 미세조정 → 시뮬 벤치 → DAgger) 을 그대로 씁니다.
- 시뮬은 **환경**을 실물과 맞춥니다. 시연을 만드는 방법은 실물을 그대로 따르지 않고, 실물의 움직임 방식은 시연 갈래 가운데 하나로 넣습니다.

## 2. 과제

| 항목 | 내용 |
|---|---|
| 순서 | ① 거치대에서 스포이드를 쥐어 꺼냄 → ② 비커에 넣고 고무 벌브를 눌렀다 놓아 물을 빨아들임 → ③ 24 칸 판의 목표 칸 위에서 벌브를 눌러 물을 떨굼 → ④ 스포이드를 거치대에 다시 꽂음 |
| 목표 칸 | 24 칸 가운데 빨간 코인으로 표시한 칸 — 판마다 무작위 |
| 성공 | 목표 칸에 물이 들어감 — 실물 판정과 같은 뜻으로 시뮬에서 정함 |
| 매 장면 바뀌는 것 | 물체 배치 (책상 위 팔이 닿는 곳 안), 목표 칸, 조명 밝기 · 색 (튜브 실험과 같은 범위). 어느 물체를 옮길지와 판 각도는 정하는 중 |

## 3. 시뮬 구성

| 항목 | 시뮬 |
|---|---|
| 실험대 | 튜브 실험의 실물 재현 실험대 그대로 — 책상 · 받침대 · 벽 · 조명 (차가운 색 \~ 따뜻한 색) · 카메라 |
| 물체 | 비커 (노란 액체, 실물 사진 색) · 24 칸 판 · 스포이드 (맑은 유리관 + 고무 벌브) · 거치대 (트인 앞쪽이 3인칭 카메라를 향함) · 목표 표시 코인 |
| 겉모습 맞추기 | 물체마다 따로 실물 사진과 나란히 놓고 눈으로 맞춤 — 유리관은 맑은 유리, 판 · 비커는 흰색 (또는 살짝 푸른 흰색) 에서 투명도를 조절 |
| 그리퍼 · 벌브 | 시뮬 보조 (쥔 동안 붙이기 · 막히면 꽉 쥐기) 를 쓰지 않음 — 실물에 없는 도움이라 sim-to-real 에 맞지 않음. 대신 AG-95 시뮬 그리퍼 모형과 벌브 접촉 재질을 고치고, 쥐는 힘은 실물과 거의 같게 |
| 시작 자세 | 실물 쪽에서 받은 값 (사진으로 어림하지 않음) |

## 4. 시연 설계

튜브 실험에서 「너무 깨끗한 시연만 많이」 모아 학습한 결과가 좋지 않았던 것을 반영해, 여러 갈래의 시연을 섞고 DAgger 로 보완합니다.

| 갈래 | 비율 | 내용 |
|---|---|---|
| 맞추는 빠르기 | 느리게 맞추기 75 % · 빠르고 정확하게 25 % | 느리게 맞추기 = 실물처럼 거치대에서 쥐고 올리기 · 비커에 넣기 · 판에 떨구기 앞에서 천천히 맞춤 |
| 흔들기 | 흔들기 70 % · 안 흔들기 30 % | 흔들기 = 일부러 조금 밀었다가 바로잡음 |
| 실패에서 다시 하기 | — | 쥐기 실패 · 다시 쥐기 같은 판은 시연을 먼저 만든 뒤 DAgger 에서 다룸 |

- **시연 길이:** 실물 빠르기로 시연을 만들어 가장 긴 값 · 평균 · 가운데 값을 보고 정함 (실물 FR5 수집은 한 판 1 분 안팎). 너무 빠른 동작이 섞이지 않는지 (실물에서 위험하지 않은지) 함께 확인
- **벤치 시간 제한:** 100 초
- **데이터 양:** 로봇마다 1,000 판 계획 + DAgger
